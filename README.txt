AL HOSN—UNITED WEBSITE

HOW TO OPEN
1. Extract the ZIP file.
2. Open the al_hosn_united_website folder.
3. Double-click index.html to open the website in your browser.

FILES
- index.html: website content and page structure
- style.css: colours, layout, typography and responsive design
- script.js: mobile navigation, scroll reveal and automatic copyright year
- assets/: six new generated architectural and interior images

EDITING
- Change the text in index.html.
- Change colours, spacing and fonts in style.css.
- Keep the assets folder beside index.html so the photos continue to load.
- The phone number is connected with a tap-to-call link.

Note: The supplied reference screenshots did not include separate original photo files,
so the site uses the photographic areas from those screenshots as its image assets.
Replace the images in assets/ with your own project photos when available.
